README – High School General Knowledge Quiz (Java)
 Project Overview

The High School General Knowledge Quiz is a simple console-based Java application designed for students.
It asks multiple-choice questions, takes the player's name, checks answers, tracks score, and finally saves the result to a file.

This project is suitable for beginner Java learners, school projects, and OOP/Console application practice.

 Features

Takes the player’s name

Asks 10 General Knowledge MCQ questions

Accepts input (a/b/c/d)

Shows correct or wrong feedback

Calculates final score automatically

Saves result in a text file (scores.txt)

Simple and easy-to-understand Java code
